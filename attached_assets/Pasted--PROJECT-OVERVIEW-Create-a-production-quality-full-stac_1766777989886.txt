📌 PROJECT OVERVIEW
Create a production-quality full-stack Public Infrastructure Issue Reporter web application that enables citizens to report local civic issues (roads, drainage, streetlights, garbage, etc.), vote on issues, and track resolution status, while allowing Admins and Super Admins to manage issues and administration efficiently.
⚠️ IMPORTANT RULE:
All new changes must be implemented WITHOUT breaking or disrupting any existing backend logic, frontend behavior, APIs, or UI flows, except where explicitly modified below.
